# ИИ: Лаборатория будущего

Статический русскоязычный учебный веб-сервис для учащихся 10–14 лет. Работает на обычных HTML, CSS и JavaScript: без Node.js, базы данных, регистрации или серверной части.

## Возможности
- Главная панель, XP, уровни и локальный прогресс.
- 6 подробных уроков по AI-грамотности.
- Конструктор промптов с ролью, задачей, аудиторией, контекстом, форматом и критериями качества.
- 6 интерактивных кейсов о распознавании синтетического контента.
- Тренажёр проверки фактов.
- Безопасность, приватность, авторство и этика.
- Словарь из 16 терминов с поиском.
- Финальный тест, достижения и сохранение прогресса в localStorage.

## Локальный запуск
Распакуйте архив и откройте `index.html` в браузере. Интернет и установка программ не нужны для основных функций. Шрифт может загружаться из Google Fonts; без интернета используется системный шрифт.

## Публикация на GitHub Pages
1. Создайте репозиторий: https://github.com/new
2. Загрузите `index.html`, `styles.css`, `app.js` и `README.md` в корень репозитория.
3. Откройте **Settings → Pages**.
4. В **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/(root)`, нажмите **Save**.
6. Дождитесь публикации; адрес появится в разделе Pages.

## Важно
- Мастер промптов — учебный конструктор, а не подключение к внешней модели. Он не отправляет данные пользователя в ИИ-сервис.
- Прогресс хранится в текущем браузере на текущем устройстве; между устройствами не синхронизируется.
- Детектив учит оценивать доказательства, но не является настоящим автоматическим детектором ИИ. По одному визуальному признаку часто нельзя надёжно установить происхождение контента.
- Перед использованием с классом учителю стоит проверить содержание и адаптировать задания под программу занятий.
